# PACMAN-python

Implementación del clásico juego Pac-Man desarrollada como proyecto
de la asignatura de Programación Orientada a Objetos del Grado en
Ciencia e Ingeniería de Datos.

## Descripción

El proyecto implementa una versión del juego Pac-Man utilizando
Python y los principios de programación orientada a objetos.

## Estructura del proyecto

- `classes/`: contiene las clases utilizadas en la implementación.
- `.gitignore`: archivos excluidos del control de versiones.

## Tecnologías

- Python
- Programación Orientada a Objetos
- Git / GitHub
  
## Requisitos

- Python 3.x
- Pyxel
